# Portfolio positioning

RAGTree should be one of the strongest projects in the portfolio because it connects research, software engineering, and real GenAI engineering.

## CV bullet

Developed RAGTree, a professional Semantic RAG framework for grounded document AI, supporting relation extraction benchmarks, ontology-guided retrieval, KG-RAG, agentic and multi-agent RAG, evaluation metrics, runtime/CO2 analysis, provider abstraction, reproducible experiments, and portfolio-ready documentation.

## Short interview pitch

RAGTree is my framework for turning advanced RAG research into reusable software. It began as a benchmark for document-level relation extraction, but I redesigned it as a broader Semantic RAG library. The idea is to separate tasks, methods, retrievers, LLM providers, evaluators, and exporters so the same framework can support question answering, relation extraction, claim verification, summarization, ontology linking, and graph construction. It also preserves rigorous evaluation, including gold-based metrics, no-gold evaluation, runtime tracking, and CO2 estimation.

## Recruiter message

The goal is to show not only that I can build RAG prototypes, but that I can transform advanced AI research into modular, installable, testable, and reusable software.

## Demo strategy

The best portfolio demo should be simple:

1. user asks a question over a small technical document;
2. RAGTree retrieves evidence;
3. RAGTree generates a grounded answer;
4. the output shows citations/evidence;
5. a second command runs a relation extraction benchmark;
6. evaluation metrics are displayed.

This demonstrates both accessibility and depth.
